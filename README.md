# GRUPO H&M - Enterprise Software & AI

Sitio web corporativo de alto impacto para **GRUPO H&M**, enfocado en soluciones de inteligencia artificial, automatización y desarrollo de software premium.

## 🚀 Características
- **Cotizador IA Premium**: Sistema interactivo para estimar costos de proyectos en tiempo real.
- **Portafolio Interactivo**: Galería de proyectos con visor de detalles y carrusel de imágenes.
- **Chatbot Inteligente**: Agente de servicio al cliente integrado.
- **Diseño Glassmorphism**: Estética moderna con efectos de cristal, gradientes dinámicos y animaciones de alto rendimiento.
- **Optimización Móvil**: Experiencia fluida y responsiva adaptada para dispositivos táctiles.

## 🛠️ Tecnologías
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Animaciones**: Particles.js, ScrollReveal, Custom Cursor Engine.
- **Backend**: Node.js (Express) para el servidor de producción.
- **Deployment**: Preparado para Railway y GitHub.

## 📦 Instalación y Uso Local
1. Clona el repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```

## ☁️ Despliegue en Railway
Este proyecto está configurado con `nixpacks.toml` para un despliegue automático y eficiente en Railway. Simplemente conecta tu repositorio de GitHub y Railway se encargará del resto.
